# IT-Help-Desk-Customer-Satisfaction-Service-Performance-Analysis-
Conducted an extensive data analysis project using Microsoft Excel to evaluate 100,000 IT Help Desk service request records, focusing on customer satisfaction, case severity, service agent performance, and monthly service request trends. The primary objective was to transform raw service request data into meaningful business insights that could help improve operational efficiency and customer support performance.

Performed data cleaning and data completion to ensure data accuracy and consistency. Retrieved missing customer satisfaction scores from multiple worksheets using the XLOOKUP function, ensuring a more complete dataset for analysis. Utilized COUNTIF to calculate the total number of cases assigned to and resolved by individual service agents. Applied AVERAGEIF to calculate average customer satisfaction scores and evaluate individual agent performance.

Created Pivot Tables to summarize service request data and identify the Top 5 service agents based on average customer satisfaction scores. Conducted case severity distribution analysis to understand the proportion of Minor, Normal, Major, Critical, and Unclassified cases. Used percentage calculations and Pivot Tables to evaluate the distribution of different case categories. Developed a Pie Chart with percentage labels to present case severity distribution effectively.

Performed Month-on-Month (MoM) service request trend analysis by extracting month numbers from submission dates using the MONTH function and calculating monthly case frequencies using COUNTIF. Calculated case resolution time through date-time subtraction and arithmetic operations to assess service handling efficiency.

Developed visual representations using Pie Charts and Line Charts to communicate key findings, highlight monthly fluctuations, and identify service request patterns. Leveraged Excel formulas, data summarization techniques, and visualization tools to present actionable insights into customer satisfaction, case management, and service agent productivity.
